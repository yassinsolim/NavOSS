# Coverage gaps: no standard yet

Do not invent a rule for these. Decide with the owner, then record the decision with evidence and move it to `rules.md`.

| Area                             | What is missing                                                                                                                                                                                        | Evidence                                                     |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| Dynamic Type policy              | Caps (`maxFontSizeMultiplier`) are chosen per component (1, 1.2, 1.3, 1.4, 1.5 appear). There is no written scale for which surface gets which cap.                                                    | `grep maxFontSizeMultiplier apps/mobile/src`.                |
| Text-size change mid-session     | Switching to the largest size during a trip left the lane/exit banner laid out at the old size until relaunch. Known, not fixed.                                                                       | Comment on #84.                                              |
| VoiceOver listening              | Labels are verified through the accessibility tree; no VoiceOver listening pass or focus-order standard is recorded.                                                                                   | #78 "Not verified".                                          |
| CarPlay template limits          | No record of Apple's per-template item and text limits; no CarPlay copy length budget.                                                                                                                 | `docs/architecture/carplay.md`.                              |
| Interactive CarPlay verification | No head-unit result recorded for any template flow; the harness mocks template chrome.                                                                                                                 | #77 "Not exercised"; `docs/release/next-build-checklist.md`. |
| Phone community UI               | Map layer, report sheet, Still-there sheet, consent and Reset identity UI states are not recorded here (built in a separate change).                                                                   | #85 follow-ups.                                              |
| "Anonymous" wording              | Fixed: the CarPlay setting detail no longer says "anonymous" and matches `docs/privacy.md` ("data minimisation with a threshold, not anonymity"). Keep it that way for any new traffic or report copy. | `CommunityReports.swift`; `docs/privacy.md`.                 |
| Offline state design             | Offline maps UI (#83, merged) states and copy are not yet recorded here; its tests are `apps/mobile/test/offline-copy.test.ts`.                                                                        | #83 (merged).                                                |
| Website visual regression        | No automated check of layout, contrast or dark mode on the site; verified by hand.                                                                                                                     | `apps/site/test`.                                            |
| Localisation                     | English (Canada) only; no French or RTL decision. Spoken guidance uses en-CA phrasing.                                                                                                                 | `copy.md`.                                                   |
| Spoken copy review               | No eval or checklist for spoken prompts beyond unit tests of the planner.                                                                                                                              | `NavigationSpeechPlanner.swift` tests.                       |
| Motion for guidance camera       | Camera easing constants are code, not a documented standard (Reduce Motion on the map camera is unaddressed here).                                                                                     | #77, `NavOSSCarPlayMapViewController.swift`.                 |
