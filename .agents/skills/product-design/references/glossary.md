# Glossary: names to use

| Term                                             | Meaning, and where it is canonical                                                                                                |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| NavOSS                                           | The product. Not "Nav OSS", not "NavOSS app" in headings.                                                                         |
| Directions / Start / End                         | Phone flow: place details, Directions, route preview, Start, End.                                                                 |
| Go                                               | CarPlay route-preview start. Siri and the App Intent only open the preview; Go is still required.                                 |
| Keep route / Accept new route                    | Phone ask-first reroute offer. CarPlay: **Use new route** / **Keep mine**.                                                        |
| Rerouting: Automatic / Ask first / Keep my route | Reroute consent modes (`adaptive`, `ask-first`, `keep-route`) in guidance settings.                                               |
| Speeding warning                                 | 0, 5 or 10 km/h over, plus an optional spoken reminder.                                                                           |
| Share road reports                               | Switch (off by default). Without it, every report is a private draft on the device.                                               |
| Spoken road reports                              | Switch for a short spoken alert for a report ahead.                                                                               |
| Share traffic speeds                             | Switch (off by default) for opt-in community traffic.                                                                             |
| Reset community identity                         | Deletes the installation, its reports and answers from the server and forgets the App Attest key on the phone.                    |
| Still there? / Not there                         | The question after passing a report, and its answers.                                                                             |
| Road report                                      | One of eight fixed types: crash, road closed, slow traffic, construction, pothole, object on road, other hazard, stopped vehicle. |
| Private draft                                    | A report kept on the device (up to 25, two hours).                                                                                |
| Community traffic                                | Live traffic built from opted-in driver speeds. Off on the server by default.                                                     |
| Official safety camera                           | Calgary intersection safety camera record (red light and speed on green).                                                         |
| Technical beta                                   | Current release status wording. Not "alpha" in new copy, not "beta" in a public App Store listing.                                |
| Companion                                        | The phone screen shown while CarPlay is connected.                                                                                |
