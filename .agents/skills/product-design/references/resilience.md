# Resilience: the states every surface designs

A surface is not done until each state it can reach has been designed and looked at. Use `StateView` (loading, empty, error) and `Banner` (inline degraded, offline, permission, information).

| State                              | How it arises                                                            | Existing behaviour to follow                                                                                                                                                                                                                                             |
| ---------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Loading                            | Search, route, details, offline manifest                                 | `StateView visual="loading"`; stable labels; CarPlay lists say "Searching…" first (#77).                                                                                                                                                                                 |
| Empty                              | No results, no saved places, no reports in the area                      | `StateView` with a next step. Never a blank list.                                                                                                                                                                                                                        |
| Error                              | Request failed, route not found                                          | Say what failed and offer a retry or alternative (CarPlay voice failure offers retry, typing or saved places, #77).                                                                                                                                                      |
| Offline / service unavailable      | API unreachable                                                          | "Service unavailable" pill on the map and a banner in the explore sheet; the map still works (`exploreServiceNotice`, #78).                                                                                                                                              |
| Location denied or no fix          | Permission off, GPS not available                                        | Map pill plus an explanation with a Settings action; "Current location unavailable" for no fix (#78).                                                                                                                                                                    |
| Outside coverage                   | The location is outside what the server declares                         | "Outside current coverage" naming the server's own coverage wording (#84).                                                                                                                                                                                               |
| Old server / feature not available | Deployed API predates `/v2/routes`, community, traffic, offline manifest | Degrade quietly: v1 fallback, no lanes, "No live traffic", "Not available yet" in CarPlay community settings. No error, no capability claim; the offline-maps sheet (#83) does the same: "Offline maps are not available yet" when `/v1/offline/manifest` is 404 or 503. |
| Feature off on the server          | `features.communityReports` false; `/v2/traffic/status` not accepting    | The report control keeps private drafts; traffic sharing reports `unavailable(not-accepting)` (#85).                                                                                                                                                                     |
| Degraded data                      | A source is stale or missing                                             | Name the data source and say it is not live or incomplete (`searchSourceLabel`).                                                                                                                                                                                         |
| Unsupported device                 | No App Attest                                                            | Reads keep working; writing says "This iPhone cannot send community reports." (`CommunityReports.swift`).                                                                                                                                                                |
| Rate limited / too far / not found | Community write rejections                                               | Plain, short messages from the native error mapping; no codes shown.                                                                                                                                                                                                     |
| Large text                         | Accessibility Dynamic Type sizes                                         | Text growth capped on guidance and map chrome; titles wrap; fixed footers stay fixed (#78). Changing size mid-session is not handled everywhere (see `exemplars/pr-84-routes-v2-clients.md`).                                                                            |
| Reduce Motion                      | Accessibility setting                                                    | Animations collapse to their end state (`ReduceMotion.System`).                                                                                                                                                                                                          |
| Unknown / extreme content          | Long road names, many lanes, a missing speed limit                       | Unknown and unlimited limits show no number and never warn (#84); signposts are read only when present.                                                                                                                                                                  |

## Old-server rule

Anything that reads a `/v2/*` capability must treat 404, an unreadable response and "flag false" as the same quiet state, ask at most once per launch (the traffic status is remembered per launch, #85) and never claim the capability. Verify by running the app against `https://navoss-api.yassin.app` through a write-blocking local proxy, or the recorded fixtures (`apps/mobile/test/fixtures`).
