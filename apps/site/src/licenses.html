Documentation and brand assets remain all rights reserved unless their file or directory states otherwise. Third-party dependencies, fonts, map data, and public datasets retain their own terms.

Fonts

The app and this site use Atkinson Hyperlegible Next by the Braille Institute of America, licensed under the SIL Open Font License 1.1. The site serves a subset of the font from this domain; no font service is contacted.

Canonical texts and notices

A build that includes GooglePlacesSwift exposes that SDK's bundled open-source licence information inside the app under About and Privacy. The restricted API key is supplied by the build environment and is not stored in this repository.
